# Security policy

Roteador is currently in v0 development and does not yet promise a stable support window.

If you discover a vulnerability, please use GitHub's **Report a vulnerability**
(private vulnerability reporting) feature for this repository, if enabled.
Otherwise contact the repository maintainer privately through an established
channel. Do not publish exploit details or secrets in a public issue.

Never commit API keys, access tokens or credentials to the repository.
Consumers must provide their own authentication, authorization, rate limiting
and operational controls appropriate to their deployment.
